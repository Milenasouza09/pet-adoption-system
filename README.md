# 🐾 Sistema de Adoção de Pets

Projeto desenvolvido para simular uma plataforma de adoção de animais utilizando arquitetura MVC.

O sistema permite visualizar e gerenciar informações relacionadas aos pets disponíveis para adoção.

---

## 🚀 Tecnologias utilizadas

- PHP
- HTML
- CSS
- Banco de Dados
- Arquitetura MVC

---

## 📋 Funcionalidades

- Visualização de pets disponíveis
- Organização em Model, View e Controller
- Interface web para interação do usuário
- Integração com banco de dados

---

## 🎯 Objetivo do projeto

Praticar conceitos de desenvolvimento web, banco de dados e organização de aplicações utilizando arquitetura MVC.
